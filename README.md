# QPC-SDFT-project
Python implementation of 2D Kohn–Sham spin-DFT (LSDA, Tanatar–Ceperley correlation) in a plane-wave basis for a GaAs quantum point contact. Self-consistent spin densities, gate-screened Hartree, Zeeman ramp. Reproduces local moment formation behind the 0.7 conductance anomaly (Hirose, Meir &amp; Wingreen 2003).
